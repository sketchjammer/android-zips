# Hereitis Privacy Policy **Last Updated: September 20, 2026** Hereitis ("the App") is an interactive game and inventory-style application that allows users to create and play their own games, questions, audio, images, videos, and other media. This Privacy Policy explains what information Hereitis accesses, how it is used, and how it is handled. ## 1. Information We Collect Hereitis is designed to operate primarily with information provided or created by the user. The App may access the following information when the user chooses to use the related features: ### Camera The App may request access to the device camera for features that allow the user to take photographs or use the camera as part of creating game content. Camera access is only used when the user activates a camera-related feature. ### Microphone The App may request microphone access when the user chooses to record audio. Recorded audio is used as game or user-created media within the App. ### Photos, Images, Audio, and Other Media The user may select images, GIFs, audio files, videos, or other media from their device for use in the App. These files are used to create and customize the user's games. ### Game and User-Created Content The App may store information created by the user, such as: * Contestant names * Game questions * Categories * Room names * Inventory or item information * Game settings * User-created audio * User-selected images and GIFs * Other game customization information This information is used to operate and customize the App. ## 2. How Information Is Used Information and media accessed or created by the App may be used to: * Create and play games * Display questions and answers * Identify contestants * Play user-selected sounds and animations * Customize game categories and rooms * Display user-created game content * Provide camera and audio recording features * Save the user's game settings and content Hereitis does not use this information for advertising profiling or selling personal information. ## 3. Information Sharing Hereitis does not sell users' personal information. The App does not intentionally share personal information with third parties for advertising purposes. If the user chooses to open an external website or download content through a link provided in the App, that website is governed by its own privacy policy and terms. ## 4. Internet Access Some features of Hereitis may use an Internet connection to display web pages or access optional downloadable game media. The App may provide links to websites containing additional game resources. Hereitis does not require users to create an online account in order to play the game. ## 5. Storage of Information Game information and media selected or created by the user may be stored on the user's device. The user is responsible for the content they choose to add to the App. Deleting the App may remove locally stored application data, depending on the Android device and its settings. ## 6. Permissions Depending on which features the user uses, Hereitis may request Android permissions such as: * Camera * Microphone * Access to selected media or files Permissions are requested so the corresponding features can function. Users can manage or revoke permissions through Android's device settings. ## 7. Children's Privacy Hereitis is not specifically directed toward children under 13. The App does not knowingly collect personal information from children for the purpose of creating user profiles or advertising. Parents or guardians who believe that a child has provided personal information may contact us so that the situation can be reviewed. ## 8. Hereitis does not control those websites and is not responsible for their privacy practices. Changes to This Privacy Policy This Privacy Policy may be updated from time to time as Hereitis develops new features or changes how information is handled.
